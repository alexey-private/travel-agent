# S7 — Push-уведомления на языке подписчика

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ежедневное напоминание о завтрашних событиях приходит на языке, который пользователь выбрал, а время в нём отформатировано по этой же локали.

**Architecture:** Cron уже группирует подписки по `session_id`, чтобы не дёргать календарь дважды на одного человека. Тот же `session_id` — ключ в `user_service_preferences`, поэтому язык добирается одним `LEFT JOIN` в уже существующем запросе, без дополнительного обращения к БД на пользователя. Тексты уведомлений — маленький словарь на три языка внутри `backend-langgraph`.

**Tech Stack:** node-cron, web-push, PostgreSQL, `Intl.DateTimeFormat`, Jest.

**Spec:** [2026-08-28-i18n-hebrew-design.md](../specs/2026-08-28-i18n-hebrew-design.md) — §8.

## Global Constraints

См. [индекс планов](2026-08-28-i18n-hebrew-index.md#global-constraints). Важное именно здесь:

- Cron бежит по всем подписчикам сразу — язык обязан браться пер-пользователя, а не глобально из окружения.
- Пользователь без записи в `user_service_preferences` (`LEFT JOIN` вернёт `NULL`) должен получить английское уведомление, а не упасть.
- Существующий тест `backend-langgraph/tests/unit/notifier/webPushCron.test.ts` должен остаться зелёным.
- Коммиты — только по явному разрешению пользователя.

```ts
import { DEFAULT_LOCALE, type Locale } from './locale';

/**
 * The only user-facing copy in this package that reaches a person directly —
 * everything else goes through the agent (which translates) or the frontend
 * (which has its own dictionary). Three phrases do not warrant more machinery.
 */
const TITLES: Record<Locale, string> = {
  en: "Tomorrow's reminders",
  he: 'התזכורות של מחר',
  ru: 'Напоминания на завтра',
};

const OVERFLOW: Record<Locale, (count: number) => string> = {
  en: (n) => `…and ${n} more`,
  he: (n) => `…ועוד ${n}`,
  ru: (n) => {
    const form = new Intl.PluralRules('ru').select(n);
    const noun = form === 'one' ? 'напоминание' : form === 'few' ? 'напоминания' : 'напоминаний';
    return `…и ещё ${n} ${noun}`;
  },
};

export function notificationTitle(locale: Locale): string {
  return TITLES[locale] ?? TITLES[DEFAULT_LOCALE];
}

export function notificationOverflow(locale: Locale, count: number): string {
  return (OVERFLOW[locale] ?? OVERFLOW[DEFAULT_LOCALE])(count);
}

/**
 * Calendar providers hand back times as "HH:MM" — or as free text like "all day".
 * Anything that does not parse is passed through unchanged rather than dropped.
 */
export function formatEventTime(locale: Locale, time: string): string {
  const match = /^(\d{1,2}):(\d{2})$/.exec(time.trim());
  if (!match) return time;

  const date = new Date(Date.UTC(2000, 0, 1, Number(match[1]), Number(match[2])));
  return new Intl.DateTimeFormat(locale, {
    hour: '2-digit',
    minute: '2-digit',
    timeZone: 'UTC',
  }).format(date);
}
```

- [x] **Step 3: Локализовать сборку payload**

В `backend-langgraph/src/notifier/web-push.cron.ts`:

```ts
import { DEFAULT_LOCALE, isLocale, type Locale } from '../i18n/locale';
import { notificationTitle, notificationOverflow, formatEventTime } from '../i18n/notifications';
```

```ts
export function buildPayload(
  events: { title: string; time?: string }[],
  tasks: { title: string }[],
  locale: Locale = DEFAULT_LOCALE,
): string {
  const lines: string[] = [];

  if (events.length > 0) {
    lines.push(...events.map((e) => (e.time ? `${formatEventTime(locale, e.time)} ${e.title}` : e.title)));
  }
  if (tasks.length > 0) {
    lines.push(...tasks.map((t) => `✅ ${t.title}`));
  }

  const shown = lines.slice(0, 3);
  const hidden = lines.length - shown.length;
  const body = hidden > 0
    ? `${shown.join('\n')}\n${notificationOverflow(locale, hidden)}`
    : shown.join('\n');

  return JSON.stringify({ title: notificationTitle(locale), body, url: '/' });
}
```

- [x] **Step 4: Достать язык из запроса подписок**

Заменить тип строки и запрос:

```ts
interface PushSubscriptionRow {
  id: string;
  session_id: string;
  endpoint: string;
  p256dh: string;
  auth: string;
  language: string | null;
}
```

```ts
      const result = await pool.query<PushSubscriptionRow>(
        `SELECT ps.id, u.session_id, ps.endpoint, ps.p256dh, ps.auth, p.language
         FROM push_subscriptions ps
         JOIN users u ON u.id = ps.user_id
         LEFT JOIN user_service_preferences p ON p.user_id = u.session_id`,
      );
```

`LEFT JOIN`, а не `JOIN`: подписка существует независимо от того, открывал ли
человек настройки. Без записи в `user_service_preferences` язык будет `NULL`, и
пользователь получит английское уведомление вместо никакого.
